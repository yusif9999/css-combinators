# Now Showing: Cinema Board UI

A responsive and visually appealing "Now Showing" movie board and showtimes table. This project was built to design a modern cinema user interface while focusing heavily on advanced CSS techniques.

## 🎯 Project Objective

The primary goal of this project is to practice and master **CSS Combinators** and structural styling using **Pure HTML and CSS**, without relying on any JavaScript or external CSS frameworks.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structuring of the movie cards and showtimes table.
*   **CSS3:** Custom styling, layout design, and advanced selectors.
*   **FontAwesome:** For vector icons (stars, tickets, clocks).

## 💡 What I Learned (Focus: CSS Combinators)

In this project, I deeply explored how CSS combinators manage the relationships between HTML elements. By using these selectors, I kept my HTML clean from excessive classes and handled the design logic entirely within CSS:

*   **Descendant Selector (Space ` `):** Targeting elements inside a parent without strict hierarchy limits (e.g., styling icons inside the buttons).
*   **Child Selector (`>`):** Precisely targeting direct children of a container to prevent styles from bleeding into nested elements.
*   **Adjacent Sibling Selector (`+`):** Styling an element that immediately follows another (e.g., adding specific margins to a paragraph right after a heading).
*   **General Sibling Selector (`~`):** Selecting siblings that share the same parent, useful for dynamic layout adjustments.

## 🚀 Features

*   **Movie Cards:** Displays movie posters, genres, IMDB ratings, and short synopses.
*   **Showtimes Table:** A clean, easy-to-read schedule table for different theaters and language options.
*   **Pure CSS Approach:** No JavaScript involved; all styling and layout rules are strictly handled by CSS.
